# Security Policy

## Public repository scope

This repository intentionally excludes production credentials, databases,
personal data, private AI prompts, provider secrets, and deployment settings.

## Reporting a vulnerability

Please do not open a public issue containing exploit details, credentials, or
personal data. Contact the Mentora project team privately and include the
affected component, reproduction steps, and potential impact.

## Supported version

Only the live MVP at https://mentoraedu.uz/ is actively maintained. This public
snapshot is provided for evaluation and may not match every production commit.
